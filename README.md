# SJS Seat Plan — St. James H.S. School

Installable exam seat plan app (works offline). Upload these files to a GitHub repository
(e.g. `sjs-seatplan`) and turn on **Settings → Pages → Deploy from branch → main / (root)**.
The app then opens at `https://<your-account>.github.io/sjs-seatplan/` — open it in Chrome and
tap **Install app** (or ⋮ → Add to Home screen).

Data is saved on each device only. Use **Backup** to move data between devices.
To publish an update: replace `index.html`, and change `VERSION` in `sw.js`.
